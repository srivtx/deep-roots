Computer science from the roots, upward.

Every technical field has a root layer its practitioners know and everyone else waves away. deep-roots goes down and stays there: each module rebuilds one field from the physics up, so that what others memorize, we derive. Module 01 — the memory models of programming languages — is the root of them all, and twenty-one more modules are now live: security, bugs, decompilation, Android, iOS, desktop kernels, COBOL, concurrency, compilers, databases, GPUs, networking, file systems, virtualization, browsers, hardware, cryptography, type systems, embedded, verification, ML infrastructure — connected by a thousand-plus cross-references (see the connections map). What insiders know, written down.

The second round went further: networking, file systems, virtualization, browsers, and hardware. The third round closed the ring: cryptography (where a cache miss is a breach), type systems (the theory under every language the program taught), embedded (the safety net removed), verification (the proofs behind the promises), and ML infrastructure (the tower rebuilt at datacenter scale). The method

First principles, downward. Each module starts at the physical layer and builds up — no fact is allowed to be memorized if it can be derived. Where a number matters, the number is stated and the platform named; where a simplification is made, it is flagged.

The insider test. Every chapter has a What insiders know section — the sizes, thresholds, flags, failure modes, and folklore that people inside the field use daily. See it yourself labs make every claim reproducible on a laptop: /proc, gdb, perf, ASan, heap snapshots, dumpsys. Research that nobody can check is a diary.

Quizzes with teeth, connections or it didn't happen. Questions predict output, diagnose bugs, and attack false intuitions — with worked answers. Every chapter ends by naming exactly what transfers to the other chapters and to the queued modules: one root, seventeen trees.

About

deep-roots is a learning program, not a tutorial dump. It is the education program of the srivtx line of work — a sibling of srivtx/p-rick, the research program on missing software. Where p-rick specifies software the world lacks, deep-roots rebuilds the knowledge most engineers lack. Both run the same discipline: work tracked in an automatic session ledger (agents.md), sources open, claims checkable.

Everything here is open: markdown sources, this site (GitHub Pages, dark and light), the interactive quiz, and the full roadmap. MIT-licensed — use it, teach it, fork it.
